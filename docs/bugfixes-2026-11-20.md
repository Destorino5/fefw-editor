# Release 1.4.0 follow-up — 20 November 2026

## Blessings: next level

Implements Antiadvocate/fefw-editor#45 using the existing game-data thresholds.
The new column shows total EXP, not remaining EXP. At the final threshold it
shows Max; Fortuna remains Unknown. This is display-only and does not alter
EXP rules or save layout. The product README describes the column.

## Route file preservation

The player observed that returning to the Obelisk Chamber fails without
Route_Ism. Preserve that file in whole-folder backups. Auto and chapter
checkpoints do not replace it. Do not automatically synthesize route files.
The product README now carries this note.

## Intermittent remembered-folder startup

The player initially saw Auto selected with blank fields on release 1.4.0,
then reported successful startup. Their terminal log contains Fontconfig
configuration errors/warnings, not a Python callback traceback. No causal
connection to blank fields has been established; no startup fix is claimed.
Actual timer-driven startup passed on two private Part 3 saves, and an
independent synthetic-save regression test also passes without slot switching.
Packaged-binary startup on the player's machine remains unverified.

## Validation

Archived suite run against the clean product source: 343 tests, 278 passed,
65 optional tests skipped. Six display-dependent GUI tests ran with Xorg,
including next-level refresh and remembered-folder startup. All six gods'
threshold boundaries and Fortuna's unknown progression are covered. Reading
and refreshing the new column leaves payload bytes unchanged.

Private saves and screenshots are not included in Git. Product branch:
fix/blessing-next-level, based on upstream 1.4.0. Main is unchanged.
